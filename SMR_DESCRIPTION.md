# Satisfactory Build Calculator

Plan production chains inside Satisfactory and turn the result into construction goals that update while you build.

## Main features

- Calculates complete production chains as connected, readable cards.
- Uses recipes unlocked in the current save and imports compatible recipes registered by other mods.
- Supports alternate recipes, Power Shards, Somersloops, generators, and fuel selection.
- Shows machine counts, ingredients, raw resources, power consumption, and power generation.
- Adds a selected process card and its descendants to the construction-goal HUD.
- Tracks newly placed matching buildings automatically and updates progress when linked buildings are dismantled or reconfigured.
- Stores goals per player and includes multiplayer remote-call support.
- Includes detailed/compact views, free panning, wheel zoom, and configurable shortcuts.
- UI languages: Korean, English, Simplified Chinese, and German. Game item and building names use Satisfactory's current language.

## Default controls

- `F5`: manual complete/cancel for the selected goal
- `F6`: add the production building under the crosshair
- `F7`: show or hide construction goals
- `F8`: open or close the calculator
- `Up` / `Down`: select a construction goal
- `+` / `-`: change the selected target quantity
- `L`: link the building under the crosshair to the selected goal
- `Delete`: remove the selected goal

F5-F8 can be changed from the mod's in-game configuration page.

## Compatibility

- Satisfactory game build: `502094` or newer within the currently compatible game release
- Satisfactory Mod Loader: `3.12.x`
- First release target: Windows game client (Steam and Epic)
- Dedicated servers: not included in the first release package

## Privacy and support

This mod does not collect telemetry or contact external services.
